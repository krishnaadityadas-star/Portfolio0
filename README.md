A clean, futuristic, and responsive developer portfolio website built strictly using **pure Semantic HTML5 and vanilla CSS3**. Designed for **Builders Day 2026** at Scaler School of Technology and BITS Pilani.

---

## 💻 Technologies Used

- **HTML5 (Semantic Elements):** `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<blockquote>`, `<footer>`, headings (`<h1>`–`<h4>`), forms, inputs, and buttons.
- **CSS3 (Modern & Standard):**
  - Multi-Chromatic CSS Custom Properties / Variables (`--neon-green`, `--neon-cyan`, `--neon-purple`, `--neon-red`, `--neon-blue`, `--neon-amber`)
  - CSS Box Model (`margin`, `padding`, `border`, `border-radius`, `box-sizing: border-box`)
  - CSS Flexbox (Navigation bar, button clusters, skill pills, HUD elements)
  - CSS Grid (About pillars, 3-category skills matrix, projects gallery, responsive contact split)
  - Positioning (`relative`, `absolute`, `sticky`, `fixed`, `z-index`)
  - CSS Transitions (`transition: transform 0.25s ease, ...`)
  - CSS Keyframes Animations (`@keyframes matrixFall`, `@keyframes pulseGlow`, `@keyframes blinkCursor`, `@keyframes orbitSpin`)
  - Mobile-First & Desktop-Down Media Queries (`@media (max-width: 992px)`, `768px`, `480px`)
- **Zero JavaScript:** Completed 100% with HTML and CSS only.
- **Zero Frameworks:** No Tailwind, no Bootstrap, pure vanilla code.

## 📂 Live Interactive Projects

Each project has a dedicated, working standalone demo in the `projects/` directory:

### 1. CyberGrid // Flexbox Alignment Game
- **Location:** `projects/cybergrid/index.html`
- **Features:** A playable Flexbox arena where users click radio buttons to dynamically switch `justify-content` and `align-items`, guiding cyber-drones into target zones using pure CSS `:has()`.

### 2. OmniWeather // Atmospheric Telemetry Dashboard
- **Location:** `projects/omniweather/index.html`
- **Features:** A full planetary weather dashboard demonstrating multi-span CSS Grid cards (`grid-column: span 2`), AQI telemetry, and a 5-day predictive forecast.

### 3. Space Explorer // Orbital Simulator
- **Location:** `projects/space-explorer/index.html`
- **Features:** An interactive deep-space mission landing page with planets physically orbiting a central star using pure CSS `@keyframes orbitSpin` and 3D rotational transforms.
